# CCAO-F

This folder is primarily created for preparation for Claude Certified Associate – Foundations (CCAO-F)

## Sections 
### SDK & Environment Setup

#### Install the SDK
```typescript
npm init -y
npm pkg set type=module
npm install @anthropic-ai/claude-agent-sdk
npm install --save-dev tsx
```

#### Set API Key 
```bash
export ANTHROPIC_API_KEY=your-api-key
```
